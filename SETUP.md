# Setup (2 minutes)

Teammates: read TEAMMATES.md for the Windows setup, the per-session routine, and how Entire fits in.

1. Copy `CLAUDE.md` and the `context/` folder into the root of your hackathon repo.
   If the repo already has a `CLAUDE.md`, paste this one's contents at the top instead of overwriting.
2. Commit and push. Teammates pull.
3. Day one: fill in `context/rules.md` and `context/sponsors.md` from the event page.
4. Team habits:
   - Pull before a session, push after.
   - Append to `decisions.md`, never rewrite it.
   - One owner per file where possible.

Teammates on Codex: copy `CLAUDE.md` to `AGENTS.md` (same content).
Optional, solo only: install Hera for private cross-session memory. Do not require it for teammates.
